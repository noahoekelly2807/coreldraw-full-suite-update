## Troubleshooting Guide

### The loader will not open

Verify that the computer uses Windows 10 or Windows 11 with a compatible x64 configuration. If the download may be incomplete, download it again and run it from a normal local folder instead of a temporary browser location.

### Windows prevents the file from running

Open the file properties and inspect the permissions available to the current Windows account. On an organization-managed device, follow the applicable software installation policy or ask the administrator for guidance.

### The loader cannot save files

Place the loader in a folder where the current account is allowed to write. Protected system directories should be avoided unless the necessary administrator permissions are available.

### The download stops or fails

Try the latest download page again and check the network connection. Proxies, connection restrictions, and filtering services can interfere with retrieval of the required files.

### Offline operation does not work

Prepare the suite while the required files are accessible, then make sure the application files remain in their expected local location. If offline access is needed, do not delete the local package or cache.

### The previous build keeps opening

Look for multiple local copies of the suite and remove obsolete shortcuts from regular use. Launch the current version from the directory prepared for that build.
